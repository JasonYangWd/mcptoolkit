CRITICAL FIX #1: JSON Escaping Vulnerability
================================================================================

File: mcptoolkit/include/json/json_builder.h
Change: Updated append_escaped() function
Impact: HIGH - Ensures JSON specification compliance

- Added proper escaping for all control characters (\n, \t, \r, etc.)
- Escapes control chars (0x00-0x1F) as \uXXXX
- Prevents malformed JSON and injection attacks

================================================================================
CRITICAL FIX #2: Token Passthrough Vulnerability  
================================================================================

Files Modified:
  1. mcptoolkit/include/authentication_handler.h
     - Added decode_token() method
     - Added set_token_secret() method
     - Added compute_token_signature() method
     - Added verify_token_signature() method

  2. mcptoolkit/src/authentication_handler.cpp
     - Implemented token decoding with HMAC-SHA256 validation
     - Implemented signature verification (constant-time)
     - Added base64 encoding/decoding helpers
     - Cross-platform support (Windows CNG / OpenSSL)

  3. mcptoolkit/src/mcp_adapter.cpp
     - Updated dispatch() method to use decode_token()
     - Now decodes auth token to extract user_id
     - Validates token before accepting authentication

Impact: CRITICAL - Prevents token forgery and privilege escalation

================================================================================
MEDIUM FIX #3: Tool Definition Validation
================================================================================

Files Modified:
  1. mcptoolkit/include/mcp_adapter.h
     - Added validate_tool_definition() static method

  2. mcptoolkit/src/mcp_adapter.cpp
     - Implemented tool validation (name, description, parameters)
     - Updated handle_tools_list() to validate all tools
     - Rejects invalid tool definitions with clear error messages

Impact: MEDIUM - Prevents tool poisoning attacks

================================================================================
ADDITIONAL FIX #4: Parameter Size Limiting
================================================================================

File: mcptoolkit/src/mcp_adapter.cpp
Change: Added MAX_PARAMS_SIZE check in handle_tools_call()
Impact: MEDIUM - Prevents DoS via oversized parameters

- Limits tool call parameters to 1 MB per request
- Consistent with overall message size limit
